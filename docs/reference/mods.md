# Mods

Standalone MCP servers that extend the backend agent live under [`Mods/`](https://github.com/yw0nam/YUI/blob/main/Mods/README.md) in the repository root. Each Mod is an independent uv-project with its own Python toolchain and is not part of the app runtime.

See [`Mods/README.md`](https://github.com/yw0nam/YUI/blob/main/Mods/README.md) for the per-mod layout, router registration rules, and CI requirements.
