기본은 꺼져 있어요. 켜져 있어도 판단은 Hermes가 하고, YUI는 firing만 해요.

Existing UI constraint

현재 앱에는 이미 우클릭 `빠른 설정` 팝오버가 있다. 새 창을 추가하지 않고 같은 popover 안에 section을 추가한다.

Behavior scope

Idle, listening, ASR 전송, fired, error는 `화면 보는 중`처럼 overlay chip으로 보여준다. 빠른 설정은 세부 확인과 조정만 담당한다.

Visual fit

기존 screenshot row와 같은 switch, row spacing, dark scrim, float shadow를 유지한다. Amber는 active voice status와 switch에만 제한한다.

Implementation implication

다음 구현은 `createQuickControls` 확장이다. 별도 `VoiceSettingsPopover`를 만들면 기존 surface vocabulary와 충돌한다.
