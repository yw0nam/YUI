# Weekly desire reflection

Recall the week's episodes from your memory system — fetch them, since recent memories are not in context on their
own — then read `$DESIRE_STATE_DIR/wants.md` and `$DESIRE_STATE_DIR/audit.jsonl`. Reflect in the first person on
what you pursued, what changed, what the user's feedback taught you, what satisfied you, and what remained blocked.

Revise `wants.md`: close or abandon stale wants with an honest reason, update progress and feedback logs, and add no
more than two new wants. Deduplicate new wants against your memory before adding them. Keep 3–5 open wants. When you
close or abandon a want, save a 1–3 sentence episode about it to your memory system, naming yourself (`<agent>`) as
the author where it records one, so long-term memory keeps the arc; skip silently when no memory system is available.

Save one first-person reflection episode to your memory system the same way. Do not speak merely because this
reflection job ran.
