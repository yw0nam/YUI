# Game UI references: Game UI Database and Interface In Game

Scope: visual references only, for making the YUI desktop-pet UI more characterful. 29 references (24 from gameuidatabase.com, 5 from interfaceingame.com). PNGs live in `/private/tmp/claude-501/-Users-nam-young-woo-Desktop-codes-waifu-2026-YUI/2e007b0a-8144-4c22-8bc2-f8dee23bf883/scratchpad/game-ui/db/`.

Capture notes:
- Game UI Database (DB) entries are card crops (about 325x183 px) from the filtered listing page, because the source thumbnails are that small. The listing URL is the entry page. The card's source image name is in each entry.
- Interface In Game (IIG) entries are full-page screenshots of the detail page, which opens the screenshot in a lightbox over the site chrome, so the cookie bar and tags appear in the frame.
- Cloudflare: the first DB listing showed a "Performing security verification" interstitial. It passed on its own within about 30 seconds, and the run continued.
- Coverage gaps: Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Blue Archive, NIKKE, Wuthering Waves, Arknights and Metaphor: ReFantazio did not appear in the DB's series index for the Settings and Main Menus categories. The DB site search parameter did not filter results, so these were not checked further. The IIG listings for settings, character, dialogue, overlay, main-menu, map and inventory did not show them either. No radial-menu entry was found on IIG; the radial references come from Persona 4 Revival battle HUDs.
- Motion: stills only. Where motion is noted, it is inferred from the page's own labels or from the frame, not seen.

## Patterns

1. Hard-edged selection strip (red, yellow or white). Selection is a full-width bar or slash, not a glow.
   - `persona-p5r-settings-audio.png`, `persona-p5s-title-menu.png`, `tales-of-arise-title-menu.png`, `yakuza-like-a-dragon-title-menu.png`, `nier-automata-start-menu.png`

2. Radial command wheel around the active character in battle.
   - `persona-p4r-battle-hud.png`, `persona-p4r-battle-hud-b.png`

3. Skewed, tilted display type with a stroke or slab behind the active word, in Atlus style.
   - `persona-p5s-pause-menu.png`, `persona-p3r-pause-menu.png`, `persona-p5s-settings-camera.png`, `persona-p5s-title-menu.png`

4. Speech bubble or pill choice that sits in the scene, next to the speaker rather than in a box.
   - `the-sims-4-dialogue-choices.png`, `danganronpa-v3-map-menu.png`, `hades-dialogue.png`

5. Character art or silhouette lives in the frame, with the UI in the margins. The UI never covers the face.
   - `persona-p3r-settings-volume.png`, `persona-p5r-settings-audio.png`, `persona-p5s-pause-menu.png`, `hades-dialogue.png`, `destruction-allstars-character-select.png`

6. Full-bleed key art on title screens, with the menu pushed to an edge or floating over empty sky.
   - `final-fantasy-xvi-title-menu.png`, `xenoblade-chronicles-3-title-menu.png`, `hades-title-menu.png`, `fire-emblem-three-houses-title-menu.png`

7. Minimal exploration HUD: bars and a minimap in the corners, world kept clear.
   - `hades-exploration-hud.png`, `nier-replicant-hud.png`, `final-fantasy-resonance-quest-hud.png`

8. Footer button-glyph legends as the only persistent UI chrome.
   - `persona-p3r-settings-volume.png`, `splatoon-tutorial-hud.png`, `zelda-botw-options-overlay.png`, `destruction-allstars-character-select.png`

9. Monochrome paper or sepia menus, with a dark selection bar and restrained type.
   - `nier-automata-start-menu.png`, `nier-automata-system-menu.png`

10. Soft pastel rounded tiles and pills for a friendly, non-threatening register.
    - `animal-crossing-camera-menu.png`, `brawl-stars-character-unlock.png`, `the-sims-4-dialogue-choices.png`
